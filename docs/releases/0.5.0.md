# Browser Connector 0.5.0

Chrome Web Store update submitted for review on 2026-11-10. The Developer Dashboard
confirmed submission with automatic publication enabled after approval.

The submitted package was built from commit `2a627da`. The listing includes the
refreshed extension icon, three screenshots from the running 0.5.0 panel, and two
promo tiles. The product credit places the studio symbol between “A product by”
and “ceebee.” The plain-text listing uses “A product by ceebee.”

## Changes

- Give each tab to one agent session. Take it back or release all tabs without
  closing them. The release control stays visible while the panel scrolls.
- Approvals show the session and target tab when available. New requests preserve
  keyboard focus.
- Add the current site or enter an address in Allowed sites. The grant uses the
  exact origin shown in the panel.
- The panel skips full refreshes for unrelated tab titles and read-only requests.

## Verification

The extension typecheck and 166 extension tests passed. Isolated Chromium
verified the tab, approval, and site controls. The published npm companion
`0.4.0` connected to the locally installed `0.5.0` extension. The uploaded Store
ZIP matched the extension build with its development key and source maps removed.
